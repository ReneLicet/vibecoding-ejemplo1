# 🎮 Cyber Tac Toe (Tres en Raya)

Un juego de **Tres en Raya (Tic Tac Toe)** interactivo con estética **Cyberpunk / Tecnológica** basada en rojo neon, negro profundo y amarillo brillante.

## ⚡ Características Destacadas

- 🧠 **Inteligencia Artificial Imbatible:** Algoritmo **Minimax** para el modo de juego invencible `vs IA Cyber Core`.
- 🤖 **Modo IA Fácil & Modo 2 Jugadores (Local):** Cambia de modo en cualquier momento.
- 🎨 **Estilo Visual Tecnológico:** Paleta futurista inspirada en **Rojo Neon (`#FF0055`)**, **Negro Profundo (`#0A0B0E`)** y **Amarillo Eléctrico (`#FFD600`)**.
- 🔊 **Efectos de Sonido Integrados:** Sintetizados con **Web Audio API** en tiempo real (sin necesidad de archivos de audio externos).
- 🏆 **Marcador Inteligente:** Guarda las estadísticas de victorias y empates localmente (`localStorage`).
- ✨ **Animaciones y Partículas:** Animación de línea victoria láser en Canvas y explosión de partículas cyber al ganar.

---

## 🚀 Cómo Ejecutar Localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/cyber-tac-toe.git
   ```
2. Abre el archivo `index.html` en tu navegador web preferido o usa un servidor local como Live Server.
